# Product Images

Product images for the Hedamo disclosure system.

Each product in `data/products.ts` points to its image here by descriptive file name
(for example `/assets/products/Solar Panel Module.avif`). To change a product's image,
add the new file to this folder and update that product's `image` path.

## Image guidelines

- **Aspect ratio**: square (1:1) works best; cards crop to a square
- **Size**: about 800–1000px on the longest side, under 500 KB
- **Format**: JPG, WebP or AVIF
- **Background**: clean, neutral backgrounds suit the design
